## Quero contribuir, e agora?

Por enquanto, **abra uma issue em vez de um pull request**:

1. Vá em https://github.com/<dono>/tempo-cli/issues/new
2. Descreva o que você quer melhorar (bug, ideia de feature, dúvida de uso).
3. Aguarde resposta — o dono lê toda issue nova.

Se for proposta de mudança grande, descreva o problema antes de propor a solução. Se for bug, inclua o passo a passo e o que você esperava ver.

## Quando este placeholder vira regra de verdade

Este arquivo entra em vigor como CONTRIBUTING completo (fluxo de PR, code review, gates, padrão de commit, DCO/CLA) **no primeiro de dois gatilhos**:

- Primeiro pull request externo aceito; OU
- Entrada do 2º colaborador regular no projeto (alguém que vai mexer no código de forma recorrente).

Quando qualquer um disparar, este arquivo será reescrito com o fluxo real e a linha correspondente sairá do [`nao-aplica.md`](./nao-aplica.md).
